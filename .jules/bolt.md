## 2026-07-25 - [Batching Metadata Queries and Portable Awk Comparison in Bash]
**Learning:** Sequential querying of file metadata (such as file modification time via `date -r` or `stat`) inside shell loops is a major bottleneck because it spawns an external process for every single file. This can be resolved by batching file paths via `xargs stat` and processing the comparison in a single $O(N)$ `awk` execution using associative arrays. However, using `strftime` within `awk` blocks is not supported by BSD awk (such as One True Awk on macOS) and leads to compile-time syntax errors/crashes.
**Action:** Always format dates natively using BSD stat (`stat -f %Sm -t %Y%m%d.%H%M%S`) and parse GNU stat (`stat -c %y`) via string manipulation in `awk` to remain fully portable across both Linux and macOS.
